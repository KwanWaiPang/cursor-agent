# 围棋 · 弈馆

网页版围棋，支持本地双人对弈与浏览器内 AI，采用中国规则（子空皆地）。

## 功能

- 棋盘：9 / 13 / 19 路
- 人人对战 / 人机对战（执黑或执白）
- AI 难度：入门 / 普通 / 进阶 / 专家（默认专家；普通及以上为限时 MCTS）
- 规则：提子、禁自杀、同形再现（劫争）
- 双方停着后点目，自动标记死子（可手动改）
- 停着、认输、悔棋、落子音效

## 目录

```
index.html      # 页面入口
css/styles.css  # 棋盘与局内样式
js/engine.js    # 规则引擎
js/ai.js        # 本地 AI
js/app.js       # 交互与绘制
```

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/go/>

## 说明

AI 为浏览器内启发式 + MCTS 引擎：专家级会搜得更深、更偏战术（叫吃/逃气/分断），思考时间也更长。仍是休闲棋力，达不到 KataGo 等神经网络水平。
