# 围棋 · 游戏馆

网页版围棋，支持本地双人对弈与浏览器内 AI，采用中国规则（子空皆地）。

## 功能

- 棋盘：9 / 13 / 19 路
- 人人对战 / 人机对战（执黑或执白）
- AI 强度：二十五级到五段，共十二档（默认六级）
  - 二十五级到一级：本地搜索。低段故意下得松；十级起蒙特卡洛；三级会读吃子；一级搜索最久
  - 初段到五段：KataGo 模型，引擎与 Web KaTrain 相同，在浏览器里计算。段位越高，模型搜索越多
- 模型讲解：初段到五段可对每一手自动估计亏目。低段不自动算。搜索没看到的手不下结论。棋谱里可以按「模型看上一手」
- 分级练习：解题九级。前三级是基本棋形；四级起是安永吉八段与 David Ormerod 的每周一题（容易、中等、难，CC BY-NC-SA 4.0）。官子八级、每级 20 题。等级可以随时切换，不必解锁
  - 一到三级为馆内原创（提子、逃气、连接、双打、征子、扑），含镜像练习
  - 四级到九级使用安永吉八段与 David Ormerod 的每周一题（容易、中等、难），按标出的正解核对。许可 CC BY-NC-SA 4.0
  - 每题先说明目标。坐标和原因在「提示」里。需要连续应手的题会让对方落子，再轮到你，不是只摆一子
- 经典棋谱：19 路全谱，一百余局。当湖十局、唐宋与清代名局、秀策耳赤之局与御城棋、秀策对太田雄藏、对海老泽健造和村濑秀甫、道策与秀伯御城棋、丈和名局。可按棋手或局名查找，跳到某一手或有批注的地方，再打谱、猜下一手，或执一方跟谱。猜错两次会记下来，可以再练。下偏之后改由 AI 应手
- 规则：提子、禁自杀、同形再现（劫争）
- 双方停着后点目，自动标记死子（可手动改）
- 停着、认输、悔棋、落子音效

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/go/>

## 说明

二十五级到一级是浏览器内的经典搜索。初段到五段改用 KataGo 的公开小模型 `g170-b6c96`，引擎来自 Web KaTrain 的浏览器移植，第一次下载约 4MB，计算在玩家自己的浏览器里。段位越高，模型搜索越多。完整大模型大约 96MB，公开地址不允许别的网页直接读取，所以高段用的是这套小模型。

「模型讲解」从初段起自动看每一手。低段对局不自动跑模型。搜索没算到的手只提示没算到，不标成坏棋。棋谱里的「模型看上一手」随时可用。

解题四级起是 Go Game Guru 的每周一题，作者是安永吉八段和 David Ormerod，许可为 CC BY-NC-SA 4.0，这里抽出正解并写成中文说明。官子仍用公有领域的官子谱。不收录赵治勋、李昌镐等近代题集，也不整段搬不能再分发的题库。每题开局说明目标，坐标和原因在「提示」里；若谱上还有应手，对方会自动落下。看答案后要自己再走通才算过关。解题是局部题；「经典棋谱」才是 19 路整局。当湖十局带清代座子，白先。
