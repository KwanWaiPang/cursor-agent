# 围棋 · 游戏馆

网页版围棋，支持本地双人对弈与浏览器内 AI，采用中国规则（子空皆地）。

## 功能

- 棋盘：9 / 13 / 19 路
- 人人对战 / 人机对战（执黑或执白）
- AI 强度：初学 / 入门 / 初级 / 中级 / 高级 / 大师 / 高段（默认初级）
  - 初学、入门：启发式，故意下得松
  - 初级起：限时 MCTS；中级会读吃子；大师和高段额外判断征子，思考更久
- 分级练习：解题、官子各 8 级，每级 12 题。等级可以随时切换，不必解锁
  - 一到三级为馆内原创（提子、逃气、连接、双打、征子、扑），含镜像练习
  - 四级起使用公有领域古典谱：《碁经众妙》《玄玄棋经》《官子谱》，按谱上的主变化核对
- 经典棋谱：19 路全谱。当湖十局、秀策耳赤之局与御城棋、道策御城棋。可打谱、猜下一手，或执一方跟谱；下偏之后改由 AI 应手
- 规则：提子、禁自杀、同形再现（劫争）
- 双方停着后点目，自动标记死子（可手动改）
- 停着、认输、悔棋、落子音效

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/go/>

## 说明

AI 为浏览器内启发式 + MCTS。中级以上会在叫吃和倒扑里做短阅读，大师和高段会判断一路征子。高段在 19 路上思考时间大约十秒，仍然是休闲棋力，到不了 KataGo 那种神经网络水平。

练习里的古典题只收公有领域棋谱，不收录近代受版权保护的题集。解题和官子有时还有别的正着，界面按谱上的主变化判对错，看答案后要自己再走通才算过关。解题是局部题；「经典棋谱」才是 19 路整局，用来从全局看棋。当湖十局带清代座子，白先。
