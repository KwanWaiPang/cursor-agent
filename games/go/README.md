# 围棋 · 游戏馆

网页版围棋，支持本地双人对弈与浏览器内 AI，采用中国规则（子空皆地）。

## 功能

- 棋盘：9 / 13 / 19 路
- 人人对战 / 人机对战（执黑或执白）
- AI 强度：二十五级到五段，共十二档（默认六级）
  - 二十五级到一级：本地搜索。低段故意下得松；十级起蒙特卡洛；三级会读吃子；一级搜索最久
  - 初段到五段：KataGo 模型，引擎与 Web KaTrain 相同，在浏览器里计算。段位越高，模型搜索越多
- 分级练习：解题、官子各 8 级，每级 20 题。等级可以随时切换，不必解锁
  - 一到三级为馆内原创（提子、逃气、连接、双打、征子、扑），含镜像练习
  - 四级起使用公有领域古典谱：《碁经众妙》《玄玄棋经》《官子谱》，按谱上的主变化核对
  - 每题都说明目标、下一手，以及为什么下在这里。需要连续应手的题会让对方落子，再轮到你，不是只摆一子
- 经典棋谱：19 路全谱，一百余局。当湖十局、唐宋与清代名局、秀策耳赤之局与御城棋、秀策对太田雄藏、对海老泽健造和村濑秀甫、道策与秀伯御城棋、丈和名局。可按棋手或局名查找，再打谱、猜下一手，或执一方跟谱；下偏之后改由 AI 应手
- 规则：提子、禁自杀、同形再现（劫争）
- 双方停着后点目，自动标记死子（可手动改）
- 停着、认输、悔棋、落子音效

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/go/>

## 说明

二十五级到一级是浏览器内的经典搜索。初段到五段改用 KataGo 的公开小模型 `g170-b6c96`，引擎来自 Web KaTrain 的浏览器移植，第一次下载约 4MB，计算在玩家自己的浏览器里。段位越高，模型搜索越多。完整大模型大约 96MB，公开地址不允许别的网页直接读取，所以高段用的是这套小模型。

练习里的古典题只收公有领域、并且带正解的棋谱，不收录近代受版权保护的题集。每题开局就说明目标和下一手的原因；若谱上还有应手，对方会自动落下，再告诉你下一手。解题和官子有时还有别的正着，界面按谱上的主变化判对错，看答案后要自己再走通才算过关。解题是局部题；「经典棋谱」才是 19 路整局，用来从全局看棋。当湖十局带清代座子，白先。
