# 曹操传 · 战棋演义

网页端三国战棋，目标为**分阶段完整复刻**《三国志 曹操传》的系统与战役体验。  
自研素材与文案，非光荣正版移植。

## 当前进度：P1 战棋内核

- 格子地图 + 地形（平地/树林/山地/城垣/河流/官道）
- 移动 / 攻击 / 待机 / 结束回合
- 兵种：步兵、骑兵、弓兵、策士（步弓骑三角克制）
- 伤害公式致敬原作简化版；可升级
- 敌军 AI；简短战前/战后对话
- 关卡：`颍川扫荡`、`汜水关前`（通关解锁）

完整阶段见 [ROADMAP.md](./ROADMAP.md)。

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/caocao/>

## 操作

1. 点击己方武将  
2. 点击高亮格移动  
3. 选择「攻击」再点敌军，或「待机」  
4. 「取消」可撤回移动；「结束回合」提前交由敌军
