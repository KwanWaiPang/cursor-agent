# 曹操传 · 战棋演义

网页端**单机**三国战棋，目标为光荣《三国志 曹操传》**原作全关卡 / 全剧本移植**（自研素材，非正版资源搬运）。

## 当前进度：P2 全剧本 + P3 视觉精修（自研）

- 原作约 55 关战役目录已全部接入并可推进通关  
- 关间红/蓝对话影响忠奸值；马超战后进入忠臣 / 奸臣路线  
- **自研像素风**地形贴图与兵种棋子（不含原作素材）  
- 第一章 15 关手绘地图 + 具名武将；汜水/虎牢含友军自动协战  
- 机制参考 [mengde](https://github.com/wateret/mengde)（MIT）：伤害公式、命名攻击射程、地形兵种消耗、计策、关卡脚本  
- **出征部署**、装备事件特效（回合回复/增伤等）、AI 模式（固守/射程内出击/积极）  
- 第一章多关脚本事件；自研地图块 + 兵种棋子/立绘（不含原作素材）  
- **战场演出**：走格插值、攻击冲刺/斩击、受击闪白、伤害飘字、计策粒子  
- **敌军演出**：友军/敌军逐步移动与攻击、阶段横幅；水面波光与林间闪点  
- **名将 / 小兵**：武将金框立绘与「将」角标；小兵盔面立绘、棋子显示兵种简称  
- 移动/攻击范围脉冲；木质棋盘框与对话壳层  

完整阶段见 [ROADMAP.md](./ROADMAP.md)。

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/caocao/>

## 操作

1. 点击己方武将  
2. 点击高亮格移动  
3. 选择「攻击」再点敌军，或「待机」  
4. 「取消」可撤回移动；「结束回合」提前交由敌军
