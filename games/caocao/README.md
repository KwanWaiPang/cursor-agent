# 曹操传 · 战棋演义

网页端**单机**三国战棋，目标为光荣《三国志 曹操传》**原作全关卡 / 全剧本移植**（自研素材，非正版资源搬运）。

## 当前进度：P2 全剧本框架

- 原作约 55 关战役目录已全部接入并可推进通关  
- 关间红/蓝对话影响忠奸值；马超战后进入忠臣 / 奸臣路线  
- 胜负：歼灭、击破主将、回合胜利、生存、逃生  
- 宝物背包雏形（通关掉落，出征加成）  
- 第一章关名对齐原作（颖川→吕布包围）；后续章节可通，持续精修地图与剧本  

完整阶段见 [ROADMAP.md](./ROADMAP.md)。

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/caocao/>

## 操作

1. 点击己方武将  
2. 点击高亮格移动  
3. 选择「攻击」再点敌军，或「待机」  
4. 「取消」可撤回移动；「结束回合」提前交由敌军
