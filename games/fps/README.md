# 战术突击 · 3D · 游戏馆

写实军事风第一人称射击（无血腥）。纯前端运行，本地 AI，支持两种模式。

开局手持 **AK-47**（弹匣 30 / 备弹 **200**）。场上五武器：

| 武器 | 特性 |
|------|------|
| 手枪 | 副武器，机动补枪 |
| AK-47 | 高伤扫射，后坐略大 |
| M4 | 更稳更快，精准点射 |
| 霰弹枪 | 多弹丸近战爆发，远距离乏力 |
| 栓狙 | 高伤远程，开火后拉栓；腰射几乎不可用，开镜才准 |

可拾取弹药、急救包与上述枪械。敌人采用偏 CS 的恐/CT 低模造型，枪声为真实枪械采样。

玩家开局短暂无敌；受伤约 **4 秒** 未再受伤后自动回血；满血拾取的急救包会收纳，掉血后自动使用。敌人不会自动回血。

地图为更大的街道战街区（据点约 170m、大逃杀约 210m）：主干/次干道路网、可穿行楼块、巷口掩体与灯柱。

阵营：玩家与队友为红方，敌人为蓝方；**每队开局 10 人**（红方 = 玩家 + 9 名队友）；无友军伤害。红方队友在据点模式会优先靠近战术区。敌/我开火有可见弹道（蓝/红），AI 有视线才开火；受伤会寻找掩体。HUD **击杀** 仅统计玩家本人击杀。

子弹不能穿墙：实体墙与掩体会挡住玩家与 AI 的弹道与伤害（玻璃/装饰不挡）；命中头部为爆头，伤害 ×2（独立准星/音效）。HUD 提供相对视角的战术区/安全区指引与受击方位。

## 模式

- **据点清剿**：红蓝各 10 人；占据中央战术区完成占领即可胜利；多波次蓝方施压；区内有敌人时占领变慢。地图有军用补给箱。
- **迷你大逃杀**：红蓝各 10 人；安全区收缩，拾取补给箱，**清剿全部蓝方**即胜（队友阵亡不判负）。HUD 提供安全区方向指引。

## 操作

| 按键 | 作用 |
|------|------|
| WASD | 移动 |
| 左键 | 射击 |
| 右键 | 开镜瞄准 |
| R | 换弹（空弹自动换弹，约 3 秒） |
| Q | 蹲下（可走） |
| Shift | 冲刺 |
| 空格 | 跳跃 |
| Esc | 释放指针 / 暂停 |

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/fps/>

需要桌面浏览器与 WebGL；模块脚本请通过 HTTP 服务访问（不要用 `file://`）。

## 说明

表现上为受击高亮、倒地淡出与火花准星，无血腥。敌人为本地脚本 AI，非联机对战。
