# 战术突击 · 3D · 游戏馆

写实军事风第一人称射击（无血腥）。纯前端运行，本地 AI，支持两种模式。

开局手持 **AK-47**（弹匣 30 / 备弹 200），敌人采用偏 CS 的恐/CT 低模造型，枪声为真实枪械采样。

玩家受伤约 **4 秒** 未再受伤后自动回血；敌人不会自动回血。

地图为更大的街道战街区（据点约 170m、大逃杀约 210m）：主干/次干道路网、可穿行楼块、巷口掩体与灯柱。

阵营：玩家与队友为红方，敌人为蓝方；无友军伤害。敌/我开火有可见弹道（蓝/红），AI 会侧移、包抄、后撤与突进。

射击仅被实体墙与掩体遮挡（玻璃/装饰不挡弹）；命中头部为爆头，伤害 ×2。

## 模式

- **据点清剿**：占据中央战术区，抵御多波次敌方单位，完成占领即胜利。
- **迷你大逃杀**：安全区收缩，拾取补给箱，淘汰全部 AI。

## 本地运行

在仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/fps/>

需要桌面浏览器与 WebGL；模块脚本请通过 HTTP 服务访问（不要用 `file://`）。

## 说明

表现上为受击高亮、倒地淡出与火花准星，无血腥。敌人为本地脚本 AI，非联机对战。
