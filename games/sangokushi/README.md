# 三国志 · 九州涂色

网页端单机战略，**致敬**光荣《三国志 14》的大地涂色与武将体系。  
地图与引擎自研；武将数值 / 特技 / 宝物与头像来自项目组 R-C-Group 数据仓。

## 当前进度：中原大色块 + 百九十城

- **中原战区构图** + **三国志14 式大色块占田**（圆斑叠缝 + 战线描边）
- 橄榄战略底图、淡州域、地貌微染、江河分层
- 约 **190 座城池**（汉郡郡治、要县与关津；自研坐标，非光荣数据）+ 城标名牌
- 武将库 **670** 人（头像全对齐）+ 所属 / 关系 / 特技 / 宝物
- 剧本：`190 年 · 群雄割据`

完整阶段见 [ROADMAP.md](./ROADMAP.md)。数据出处与核对见 [data/rc/SOURCE.md](./data/rc/SOURCE.md)、[data/rc/AUDIT.md](./data/rc/AUDIT.md)。

## 本地运行

仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/sangokushi/>

## 操作

1. 选择势力开局（镜头自动对准己方城池）  
2. 点选己方都市 → 勾选**本城待命**武将 → **出征**  
3. 在地图点击目标：空地涂色 / **敌城或无主城**攻略（周边控制越高越易破城）  
4. **结束旬月**推进；拖拽平移，滚轮缩放；**镜头归位**可回到己方中心
