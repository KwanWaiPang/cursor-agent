# 三国志 · 九州涂色

网页端单机战略，**致敬**光荣《三国志 14》的大地涂色与武将体系。  
地图与引擎自研；武将数值 / 特技 / 宝物与头像来自项目组 R-C-Group 数据仓。

## 当前进度：战略大地重绘 + 数据仓

- **战略大地重绘**：羊皮纸州域色块 + 柔和势力涂色（去格子感），致敬三国志系列战略地图观感（自研几何，非光荣贴图）
- 中国轮廓、汉末州域、山脉脊线、长江 / 黄河 / 淮河 / 珠江
- **46 都市**历史大致经纬度；城池外观（城墙 / 城门 / 敌楼）
- 约 **338 地区（府）**；行军占地、围府攻城
- 武将库 **670** 人（头像全对齐）+ 所属 / 关系 / 特技 / 宝物
- 剧本：`190 年 · 群雄割据`

完整阶段见 [ROADMAP.md](./ROADMAP.md)。数据出处与核对见 [data/rc/SOURCE.md](./data/rc/SOURCE.md)、[data/rc/AUDIT.md](./data/rc/AUDIT.md)。

## 本地运行

仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/sangokushi/>

## 操作

1. 选择势力开局  
2. 点选己方都市 → 勾选待命武将 → **出征**  
3. 在地图点击目标：空地涂色 / 敌城攻略（控制周边地区更易破城）  
4. **结束旬月**推进；拖拽平移，滚轮缩放
