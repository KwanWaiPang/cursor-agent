# 三国志 · 九州涂色

网页端单机战略，**致敬**光荣《三国志 14》的大地涂色与武将个性体系。  
自研地图投影、地貌着色与武将数据；**非正版资源搬运**。

## 当前进度：P1 可玩骨架

- **46 都市**（历史汉末城邑骨架）+ 约 **338 地区（府）**
- 土地格 **势力涂色**；行军轨迹占地、围府后攻城
- 武将 **五维**（统 / 武 / 智 / 政 / 魅）+ **金 / 蓝 / 红个性**
- 剧本：`190 年 · 群雄割据`（曹操 / 刘备 / 孙坚 / 袁绍可选）
- 本地 AI 势力会出征扩张

完整阶段见 [ROADMAP.md](./ROADMAP.md)。

## 本地运行

仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/sangokushi/>

## 操作

1. 选择势力开局  
2. 点选己方都市 → 勾选待命武将 → **出征**  
3. 在地图点击目标：空地涂色 / 敌城攻略（控制周边地区更易破城）  
4. **结束旬月**推进；拖拽平移，滚轮缩放
