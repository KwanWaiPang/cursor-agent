# 三国志 · 九州涂色

网页端单机战略，**致敬**光荣《三国志 14》的大地涂色与武将体系。  
地图与引擎自研；武将数值 / 特技 / 宝物与头像来自项目组 R-C-Group 数据仓。

## 当前进度：P1 + 数据仓接入

- **中国轮廓地图**（细化海岸线）+ 长江 / 黄河 / 淮河 / 珠江示意
- **汉末州界**虚线分区与州名标注；**山脉脊线**（秦岭、太行、南岭等）
- **46 都市**按历史大致经纬度落点；城池有城墙、城门、敌楼外观（按规模）
- 约 **338 地区（府）**；土地格 **势力涂色**；行军占地、围府攻城
- 武将库约 **670** 人：五维、适性、特技、宝物、列传摘要 + **头像**
- 剧本：`190 年 · 群雄割据`（曹操 / 刘备 / 孙坚 / 袁绍可选）
- 本地 AI 势力会出征扩张

完整阶段见 [ROADMAP.md](./ROADMAP.md)。数据出处见 [data/rc/SOURCE.md](./data/rc/SOURCE.md)。

## 本地运行

仓库根目录：

```bash
python3 -m http.server 8080
```

打开：<http://localhost:8080/games/sangokushi/>

## 操作

1. 选择势力开局  
2. 点选己方都市 → 勾选待命武将 → **出征**  
3. 在地图点击目标：空地涂色 / 敌城攻略（控制周边地区更易破城）  
4. **结束旬月**推进；拖拽平移，滚轮缩放
