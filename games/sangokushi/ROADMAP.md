# 《三国志 · 九州涂色》路线图

目标：网页端单机战略，致敬《三国志 14》——整图中华、都市与地区、土地涂色、武将五维与个性。  
约束：自研地图/美术/数值；历史人物与地理可公开考据；不搬运光荣素材。

## 对位原作概念

| 原作概念 | 本作品对应 |
|----------|------------|
| 46 都市 / ~340 地区 | `data/cities.js` + `mapgen` 生成府点 |
| 土地涂色 | 网格 `cell.owner` 势力色叠加 |
| 地貌 CG | 程序化 biome 渐变（平原/山地/水乡/边塞/南荒等） |
| 五维 | 统 lead / 武 force / 智 int / 政 pol / 魅 charm |
| 个性 金蓝红 | `data/traits.js`，固有金色与常规蓝/红 |
| 出征占地 / 占府 | 军队路径涂色 + 府点占领 |
| 施政 / 主义 / 粮道 | 后续阶段 |
