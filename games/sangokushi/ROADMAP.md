# 《三国志 · 九州涂色》路线图

目标：网页端单机战略，致敬《三国志 14》——整图中华、都市与地区、土地涂色、武将五维与特技。  
约束：自研地图与引擎；武将数值/头像使用项目组 R-C-Group 数据；不搬运光荣官方素材。系统设计可参考《中华三国志》开源实现。

## 对位原作概念

| 原作概念 | 本作品对应 |
|----------|------------|
| 46 都市 / ~340 地区 | `data/cities.js` + `mapgen` 生成府点 |
| 土地涂色 | 网格 `cell.owner` 势力色叠加 |
| 地貌 CG | 程序化 biome 渐变（平原/山地/水乡/边塞/南荒等） |
| 五维 | 统 lead / 武 force / 智 int / 政 pol / 魅 charm（R-C-Group 表） |
| 特技 / 宝物 | `data/rc/tricks*.js` · `treasures*.js`；等级映射金/蓝展示 |
| 头像 | `assets/portraits/{id}.jpg`（R-C-Group/touxiang） |
| 出征占地 / 占府 | 军队路径涂色 + 府点占领 |
| 施政 / 主义 / 粮道 | 后续阶段 |
