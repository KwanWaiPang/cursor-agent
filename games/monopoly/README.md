# 大富翁 · 世界之旅

实体棋「世界之旅」式 **环线** 大富翁：世界城市买地、收租、升级，本地人机对战。

## 玩法

- 掷骰顺时针环行；路过起点领取 $2000
- 空地可购买，自家地可升级（小屋 → 别墅 → 酒店）
- 机会 / 命运、税收、车站飞航、监狱、阿尔卑斯度假
- 侧栏可配置起始金钱、玩家/电脑人数（合计 2–4）
